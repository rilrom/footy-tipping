<objective>
## Goal
Add a small Express backend that persists tips to a local JSON file, and wire up the dev environment to run frontend and backend together with a single command.

## Purpose
localStorage is too easily wiped. Tips data represents a full AFL season of picks — losing it would be frustrating. A local JSON file on disk survives browser clears, is human-readable, and trivially backed up. This plan establishes the persistence layer all tipping and results features will use.

## Output
- `server/index.ts` — Express server on port 3001
- `server/routes/tips.ts` — GET and POST endpoints for tips
- `server/data/tips.json` — persisted tips storage file
- Updated `package.json` — `npm run dev` starts both frontend (5173) and backend (3001) via `concurrently`
- Updated `vite.config.ts` — proxy `/api` requests to `localhost:3001`
</objective>

## Data Shape
Tips are stored per round, per player. The JSON structure:
```json
{
  "2025": {
    "1": {
      "riley": { "gameId": "teamName", "gameId2": "teamName" },
      "charlotte": { "gameId": "teamName", "gameId2": "teamName" }
    },
    "2": { ... }
  }
}
```
Keys: year (string) → round (string) → player ("riley" | "charlotte") → gameId (string) → picked team name (string)

    server/index.ts:
    - Express app on port 3001
    - Use cors() middleware (allow localhost:5173)
    - Use express.json() middleware
    - Mount tips router at /api/tips
    - Log "Backend running on http://localhost:3001" on start

    server/routes/tips.ts:
    - DATA_FILE path: `path.join(__dirname, '../data/tips.json')`
    - readTips(): read and parse tips.json, return {} if file doesn't exist
    - writeTips(data): write to tips.json with 2-space indent
    - GET /: accepts query params `year` and `round`, returns tips[year][round] or {}
    - POST /: accepts body `{ year: string, round: string, player: 'riley' | 'charlotte', tips: Record<string, string> }`, deep-merges into tips.json structure, writes file, returns { success: true }

    server/data/tips.json:
    - Create as empty object: `{}`

    Avoid: Using ESM imports in server files — use CommonJS require() or configure ts-node for CommonJS.
    Avoid: Overwriting entire tips.json on each save — deep-merge so one player's tips don't erase the other's.
  </action>
