## Squiggle API
Base URL: https://api.squiggle.com.au/
Key endpoints (query params on the base URL):
- `?q=games;year=YYYY;round=N` — games for a specific round
- `?q=games;year=YYYY` — all games for a season
- `?q=teams` — all AFL teams
- `?q=standings;year=YYYY` — ladder standings
- `?q=games;complete=100;year=YYYY` — completed games only

Game fields: id, hteam, ateam, hteamid, ateamid, date, round, year, complete (0-100), winner, hscore, ascore, roundname
Team fields: id, name, abbrev, logo

API returns JSON: `{ "games": [...] }` or `{ "teams": [...] }`
Requires a User-Agent header identifying the app (Squiggle API requirement).

<task type="auto">
  <name>Task 2: Define Squiggle API types and client</name>
  <files>src/types/squiggle.ts, src/api/squiggle.ts</files>
  <action>
    src/types/squiggle.ts — TypeScript interfaces:
    ```
    Game: { id, hteam, ateam, hteamid, ateamid, date, round, year, complete, winner, hscore, ascore, roundname }
    Team: { id, name, abbrev, logo }
    Standing: { id, rank, name, abbrev, wins, losses, draws, played, for, against }
    ```
    All fields typed (number/string where appropriate). complete is 0-100 (number). winner is string (team name) or null/empty when game not complete.

    src/api/squiggle.ts — async fetch functions:
    - `const BASE_URL = 'https://api.squiggle.com.au/'`
    - All requests must include header: `User-Agent: 'footy-tipping-app (personal)'`
    - `getGames(year: number, round?: number): Promise<Game[]>` — fetches `?q=games;year=Y[;round=N]`
    - `getTeams(): Promise<Team[]>` — fetches `?q=teams`
    - `getCurrentRound(year: number): Promise<number>` — fetches games for year, finds max round with complete < 100, returns that round number

    Avoid: Using axios or other HTTP libraries — use native fetch only.
  </action>
  <verify>`npm run build` passes TypeScript checks with no errors in these files</verify>
  <done>AC-3 and AC-4 satisfied: typed API client compiles cleanly</done>
</task>
