<objective>
## Goal
Replace plain text loading indicators with Mantine Skeleton components and add error alert handling for API failures across Tips, Results, and Leaderboard pages.

## Purpose
Currently, loading states show bare "Loading..." text and API errors are silently ignored — the UI just shows empty content. This improves perceived performance and makes failures visible to the user.

## Output
- Tips.tsx, Results.tsx, Leaderboard.tsx with Skeleton loading states
- All three pages show an error Alert if the games API call fails
</objective>
