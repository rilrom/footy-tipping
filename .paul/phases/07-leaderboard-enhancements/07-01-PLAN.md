<objective>
## Goal
Update the leaderboard round-by-round table to show game totals as `6/9` for in-progress rounds and `9` for completed rounds, in both the Games column and the score cells.

## Purpose
The current Games column shows only completed games (e.g. `6`), giving no sense of how many games are in the round. `6/9` makes in-progress rounds clear; `9` keeps completed rows clean.

## Output
- `src/pages/Leaderboard.tsx` updated with total games per round and improved display format
</objective>
