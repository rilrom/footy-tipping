- MantineProvider wrapping the app
- App.tsx using AppShell layout
- Nav.tsx using Mantine AppShell.Navbar and NavLink
- GameCard.tsx using Mantine Card, Button, Text, Badge

<task type="auto">
  <name>Task 1: Install Mantine and configure PostCSS</name>
  <files>package.json, postcss.config.cjs, src/main.tsx</files>
  <action>
    Install packages:
    - `@mantine/core @mantine/hooks` as dependencies
    - `postcss postcss-preset-mantine autoprefixer` as devDependencies

    Create `postcss.config.cjs` at root:
    ```js
    module.exports = {
      plugins: {
        'postcss-preset-mantine': {},
        'autoprefixer': {},
      },
    };
    ```

    Update `src/main.tsx`:
    - Import `'@mantine/core/styles.css'` before other imports
    - Wrap the app with `<MantineProvider>` (import from `@mantine/core`)
    - MantineProvider wraps inside QueryClientProvider > BrowserRouter

    Do NOT create a custom theme — use Mantine defaults.
    Do NOT add `@mantine/hooks` imports yet (used in later plans).
  </action>
  <verify>`pnpm install` succeeds and `pnpm run dev` starts without TypeScript or PostCSS errors</verify>
  <done>AC-1 satisfied: Mantine installed, PostCSS configured, styles imported, MantineProvider in tree</done>
</task>

<task type="auto">
  <name>Task 2: Convert App.tsx and Nav.tsx to Mantine AppShell</name>
  <files>src/App.tsx, src/components/Nav.tsx</files>
  <action>
    **App.tsx:**
    - Replace the outer `div` with Mantine `AppShell` component
    - Use `AppShell.Header` for the nav area (height={60} or similar)
    - Use `AppShell.Main` for the routes content area
    - Remove all inline styles from App.tsx
    - Keep the Routes/Route structure unchanged

    **Nav.tsx:**
    - Replace the raw `<nav>` with Mantine `Group` inside `AppShell.Header`
    - Use `Container` or `Group` for horizontal layout with the title and links
    - Replace custom `NavLink` (react-router-dom) styled links with Mantine `NavLink` component
      - Use `renderRoot` prop to integrate react-router-dom's NavLink: `renderRoot={(props) => <RouterNavLink to={to} {...props} />}`
      - Or use Mantine `Anchor` component with react-router-dom NavLink
      - Simplest: use `NavLink` from `@mantine/core` with `component={RouterNavLink}` and `to` prop
    - Title "Footy Tipping 🏉" as Mantine `Text` with `fw={700}`
    - Remove all inline styles from Nav.tsx

    Avoid: Do not use AppShell.Navbar (that's for side navbars). Use AppShell.Header for top nav.
  </action>
  <verify>App renders with a top header bar containing the title and nav links; active route highlights correctly; no inline styles in App.tsx or Nav.tsx</verify>
  <done>AC-2 and AC-3 satisfied</done>
</task>

<task type="auto">
  <name>Task 3: Convert GameCard.tsx to Mantine Card and Buttons</name>
  <files>src/components/GameCard.tsx</files>
  <action>
    Replace all inline styles with Mantine components:

    - Outer wrapper: Mantine `Card` with `shadow="xs"` and `withBorder` (or `Paper`)
    - Date line: Mantine `Text` with `size="xs"` and `c="dimmed"`
    - Team buttons layout: Mantine `Group` with `justify="space-between"`
    - Team buttons: Mantine `Button` with `variant="default"` when not selected, `variant="filled"` when selected (tip === teamName)
    - "vs" separator: Mantine `Text` with `c="dimmed"`
    - Winner/score line: Mantine `Text` with `size="sm"` and `ta="center"`

    Button behavior:
    - Selected team: `variant="filled"` (uses Mantine primary color)
    - Unselected: `variant="default"`
    - Disabled state: use `disabled` prop on Button (Mantine handles the styling)

    Remove the `teamButtonBase`, `selectedStyle`, `buildTeamStyle` helper functions — replace with conditional `variant` prop.
    Remove all inline styles.
    Keep the `GameCardProps` interface and `formatDate` function unchanged.
  </action>
  <verify>Games render as cards with two team buttons; clicking selects a team (button fills); disabled games show both buttons as disabled; winner/score appears below when game is complete</verify>
  <done>AC-4 satisfied: GameCard uses only Mantine components, no inline styles</done>
</task>
