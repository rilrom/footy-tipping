  <files>src/pages/Tips.tsx</files>
  <action>
    Replace all inline styles with Mantine components:

    **Player selector:**
    - Replace the two styled `<button>` elements with Mantine `SegmentedControl`
    - `data={[{ value: 'riley', label: 'Riley' }, { value: 'charlotte', label: 'Charlotte' }]}`
    - `value={player}` and `onChange={(v) => setPlayer(v as Player)}`

    **Round navigator:**
    - Replace styled `<button>` elements and span with Mantine `Group` containing:
      - `ActionIcon` with `variant="default"` for prev/next (use chevron icons or `‹`/`›` as text children)
      - `Text` with `fw={600}` for the round label
    - Use `disabled` prop on ActionIcon

    **Page header area:**
    - Replace raw div+h1 with Mantine `Group` containing `Title` order={1} and a `Text` for "Saving..."
    - Saving indicator: use Mantine `Loader` size="xs" or `Text size="sm" c="dimmed"`

    **Games list:**
    - Replace the outer div with Mantine `Stack` with `gap="sm"`
    - Loading/empty states: use Mantine `Text c="dimmed"`

    **Type alias:** Keep `type Player = "riley" | "charlotte"` — this is a union type with no reasonable interface alternative, so it stays as `type`.

    Remove all inline styles and helper style functions (`playerBtn`, `navBtn`).
  </action>
