<objective>
## Goal
Build the Results page showing completed game results for a round, each player's tip for that game, and whether they got it right — plus a round score summary ("Riley: 5/9 | Charlotte: 4/9").

## Purpose
Seeing who got what right each round is the payoff for tipping. Without results, the tips are just guesses with no feedback.

## Output
- `src/pages/Results.tsx` — round results with correct/incorrect tip display and round score
- `src/App.tsx` updated — wire Results page into the existing /results route
</objective>

## API Available
**Squiggle:**
- `getGames(year, round)` → `Game[]`
  - `game.complete` — 0–100 (100 = finished)
  - `game.winner` — team name string (empty string if not complete)
  - `game.hscore`, `game.ascore` — scores (null if not played)

**Backend:**
- `GET /api/tips?year=Y&round=R` → `{ riley: Record<string,string>, charlotte: Record<string,string> }` or `{}`

## Scoring Logic
For each game where `game.complete === 100`:
  - A tip is correct if `tips[player][game.id.toString()] === game.winner`
  - Count correct tips / total completed games = round score

## Tips Key Pattern
`tips[player][game.id.toString()]` — same key used in Phase 2.

    function calcScore(games: Game[], playerTips: Record<string, string>): { correct: number; total: number } {
      const completed = games.filter(g => g.complete === 100)
      const correct = completed.filter(g => playerTips[g.id.toString()] === g.winner).length
      return { correct, total: completed.length }
    }
