## Goal
Add a season leaderboard showing cumulative correct tips for Riley and Charlotte across all completed rounds, with a round-by-round breakdown.

## Purpose
The leaderboard is the competitive element that makes tipping fun all season — "Riley leads 47–39 after 12 rounds". Without it, there's no scoreboard for the season.

- `src/pages/Leaderboard.tsx` — season totals + round-by-round breakdown table
- `src/components/Nav.tsx` updated — add "Leaderboard" link
- `src/App.tsx` updated — add /leaderboard route
</objective>

## Backend Current Behaviour
GET /api/tips with no params → full tips.json
GET /api/tips?year=Y&round=R → tips[year][round] or {}
GET /api/tips?year=Y (no round) → currently returns full tips.json (bug — should return tips[year])

## Leaderboard Data Strategy
1. GET /api/tips?year=Y → { "1": { riley: {...}, charlotte: {...} }, "2": {...}, ... }
2. Fetch all completed games for the year: getGames(year) — filter where complete === 100
3. Group completed games by round
4. For each round with completed games:
   - Check tips for that round
   - Count correct tips per player
5. Sum across all rounds for season totals

## Squiggle API
- `getGames(year)` with no round → all games for that season
- Filter `game.complete === 100` for completed games
- `game.winner` is the correct tip value

## Constraints
- Inline styles only
- Native fetch only
- No new npm dependencies
