<objective>
## Goal
Implement a deadline detection utility and hook that determines whether a round is locked for tipping. A round is locked when the earliest game's kickoff time has passed.

## Purpose
Provides the authoritative source of truth for "is this round still open for tipping?" — a computed value from existing game data. This is the foundation Phase 9 (UI Locking) will build on.

## Output
- `src/lib/deadline.ts` — pure utility function `isRoundLocked(games)`
- `src/hooks/squiggle.ts` — new `useRoundLocked(games)` hook that re-evaluates on a 1-minute timer
</objective>

<acceptance_criteria>

## AC-1: Round Locked When First Game Has Started
```gherkin
Given a set of games for a round
When the earliest game's date is in the past
Then isRoundLocked returns true
```

## AC-2: Round Open When First Game Is In The Future
```gherkin
Given a set of games for a round
When the earliest game's date is in the future
Then isRoundLocked returns false
```

## AC-3: Empty Games Treated As Unlocked
```gherkin
Given an empty games array
When isRoundLocked is called
Then it returns false (safe default — don't block tipping if no data)
```

## AC-4: Hook Re-evaluates Automatically
```gherkin
Given the useRoundLocked hook is mounted with games
When one minute passes
Then the hook re-evaluates the lock state (so the UI auto-locks when kickoff arrives)
```

</acceptance_criteria>

<task type="auto">
  <name>Task 1: Create deadline utility</name>
  <files>src/lib/deadline.ts</files>
  <action>
    Create new file `src/lib/deadline.ts` with a single exported function:

    ```
    isRoundLocked(games: Game[]): boolean
    ```

    Logic:
    - If games is empty, return false (AC-3)
    - Find the game with the earliest date: `Math.min(...games.map(g => new Date(g.date).getTime()))`
    - Return true if that date is <= Date.now(), false otherwise

    Avoid: treating games with no date as having a date — if a game's date is falsy, skip it when finding the earliest.
  </action>
  <verify>Read the file and confirm: empty array → false, past date → true, future date → false logic is present</verify>
