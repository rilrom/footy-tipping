<objective>
## Goal
Wire `useRoundLocked` into the Tips page so that once the round's first game has kicked off, all tip buttons are disabled and a locked banner is shown. Past rounds that aren't the current round are also locked.

## Purpose
Prevents tips being saved after the round starts — the core requirement of v0.4. Phase 8 built the detection; this plan enforces it in the UI.

## Output
- `src/pages/Tips.tsx` updated to use `useRoundLocked`, show a locked alert, and pass `disabled` to all GameCards when locked
</objective>
