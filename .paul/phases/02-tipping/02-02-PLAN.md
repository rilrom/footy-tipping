<objective>
## Goal
Add a Summary page showing Riley's and Charlotte's tips side-by-side for any round, so they can compare picks before and after games.

## Purpose
Tipping is more fun when you can see where you agree and disagree with your opponent. This view lets both players check each other's picks without having to switch between player views on the Tips page.

## Output
- `src/pages/Summary.tsx` — read-only comparison view of both players' tips per round
- `src/components/Nav.tsx` updated — add "Summary" link
- `src/App.tsx` updated — add /summary route
</objective>

## API Available
- `getGames(year, round)` → `Game[]`
- `getCurrentRound(year)` → `number`
- `GET /api/tips?year=Y&round=R` → `{ riley: Record<string,string>, charlotte: Record<string,string> }` or `{}`

## Tips Key Pattern (from 02-01)
Tips are keyed by `game.id.toString()` → team name string.
GET /api/tips returns the full round object with both players.

- Read-only view — no tip editing on this page
- Reuse same round navigator pattern from Tips.tsx

    ```typescript
    type RoundTips = {
      riley: Record<string, string>
      charlotte: Record<string, string>
    }
    ```

    Effects:
    - On mount: getCurrentRound(year) → setRound
    - On round change: fetch games (sorted by date) + fetch /api/tips?year=Y&round=R → setRoundTips
      (fetch both in parallel with Promise.all)

    Layout:
    - Title: "Summary — Round N"
    - Same round navigator as Tips page (< Round N >)
    - If loading: "Loading..."
    - If no games: "No games found."

    For each game, render a row/card with these columns:
    - Riley's pick (left, right-aligned text)
    - Game matchup (centre): "HomeTeam vs AwayTeam" in muted style
    - Charlotte's pick (right, left-aligned text)

    Riley's pick cell styling:
    - If riley tipped the home team: bold, align right
    - If riley tipped the away team: bold, align right
    - If riley hasn't tipped: "—" in muted grey, align right

    Charlotte's pick cell: mirror of Riley's, align left

    Agreement indicator:
    - If both picked the same team AND both have tipped: show a subtle green background on the row (#f0fdf4) and a small "✓" badge
    - If they disagree (both tipped, different teams): normal white background
    - If one or both haven't tipped yet: slightly muted background (#fafafa)

    Card container per row:
    - border: 1px solid #e5e5e5, border-radius 8px, padding 0.85rem 1rem, marginBottom 0.5rem
    - display: grid, gridTemplateColumns: '1fr auto 1fr', gap: 1rem, alignItems: center

    Avoid: Reusing GameCard — this is a different layout (comparison, not selection).
    Avoid: Any tip-entry interaction — this page is read-only.
