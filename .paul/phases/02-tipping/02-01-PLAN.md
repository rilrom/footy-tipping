## API Available
**Squiggle (frontend):**
- `getGames(year, round)` → `Game[]`
- `getCurrentRound(year)` → `number`
- Game fields: id, hteam, ateam, hteamid, ateamid, date, round, year, complete (0-100), winner, hscore, ascore

**Backend (via Vite proxy):**
- `GET /api/tips?year=Y&round=R` → `{ riley: { gameId: team }, charlotte: { gameId: team } }` or `{}`
- `POST /api/tips` body: `{ year: string, round: string, player: 'riley' | 'charlotte', tips: Record<string, string> }` → `{ success: true }`

## Tips Data Shape
Tips for a player in a round: `Record<string, string>` where key = `game.id.toString()` and value = team name string (e.g. "Geelong").

## Constraints
- Inline styles only — no CSS framework
- Native fetch only — no axios
- No separate state management library — React useState/useEffect only

    - setSaving(true)

    - setSaving(false)
